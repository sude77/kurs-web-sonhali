# Kurs Yönetim Sistemi (Django)

Python ve Django framework'ü kullanılarak geliştirilmiş, yönetim panelli (admin tabanlı) kurs yönetim web uygulaması.

## Özellikler
- **Yönetici Paneli (Django Admin):** Kurs ekleme, düzenleme ve silme (CRUD) işlemleri
- **Yetkilendirme:** Yönetici girişi ve oturum yönetimi
- **Kullanıcı Arayüzü:** Kursların dinamik olarak listelenmesi ve detay sayfaları

## Kullanılan Teknolojiler
- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3
- **Veritabanı:** SQLite (Django ORM)
