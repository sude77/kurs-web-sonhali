# Kurs Yönetim Sistemi (Django)

Python ve Django kullanılarak geliştirilmiş, yönetim panelli ve kullanıcı hesap destekli kurs yönetim web uygulaması.

## Özellikler
- **Kullanıcı & Hesap Yönetimi (`account`):** Üyelik, giriş/çıkış ve yetkilendirme akışları
- **Kurs Yönetimi (`courses`):** Yönetici paneli üzerinden kurs ekleme, düzenleme, silme (CRUD) ve kategori/liste görüntüleme
- **Medya Yönetimi (`uploads/images`):** Kurs görsellerinin yüklenmesi ve dinamik olarak sunulması
- **Modüler Yapı (`pages` & `templates`):** Yeniden kullanılabilir şablonlar ve statik sayfa yönlendirmeleri

## Kullanılan Teknolojiler
- **Backend:** Python, Django (Django ORM)
- **Frontend:** HTML5, CSS3, Django Templates
- **Veritabanı:** SQLite (`db.sqlite3`)
